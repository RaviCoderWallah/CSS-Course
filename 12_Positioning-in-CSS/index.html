CSS Position Property Examples

1. position: static (default)

Static

Explanation: Elements are placed in the normal document flow. top, left, etc. won’t work here.

2. position: relative

Relative

Explanation: Element stays in normal flow, but you can shift it using top/right/bottom/left without affecting other elements.

3. position: absolute

Absolute

Explanation: Removed from normal flow. Positioned relative to the nearest position: relative (or parent with position set).

4. position: fixed

Scroll down to see the orange box stick to the bottom-right corner.

Fixed

5. position: sticky

Scroll, and watch the pink box stick to the top until its parent ends.

Sticky

Keep scrolling... The sticky box will stay at the top of this container until the container ends.
