Media Queries in CSS

Media queries are a feature in CSS that allow developers to apply styles based on the conditions of the device, such as screen size, resolution, or orientation. They are mainly used to create responsive web designs that adapt to different devices like mobiles, tablets, and desktops.

Types of Media Queries

  • All: Default type, applies to all devices.
  • Screen: Targets computer screens, tablets, and smartphones.
  • Print: Applies styles when printing a page.
  • Speech: Used for screen readers that read content aloud.

Max-width

The max-width rule applies CSS styles when the device width is less than or equal to the specified value. It is often used for targeting smaller devices like mobiles. 

    @media (max-width: 768px) {
      body {
        background-color: lightblue;
      }
    }

Min-width

The min-width rule applies CSS styles when the device width is greater than or equal to the specified value. It is commonly used for larger devices like tablets and desktops. 

    @media (min-width: 1024px) {
      body {
        background-color: lightgreen;
      }
    }
